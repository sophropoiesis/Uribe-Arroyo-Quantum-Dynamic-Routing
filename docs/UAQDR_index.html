01 / Research definition

Abstract

Uribe Arroyo Quantum Dynamic Routing (UAQDR) is a proposed entropy-acquisition and conditioning architecture that combines measurements from multiple quantum random-number generators (QRNGs). It uses QRNG-derived confidential control material to vary the order in which later source measurements are collected. The proposal integrates per-source health checks, authenticated provenance assumptions, cryptographic conditioning, and conservative failure policies. Its purpose is to test whether feedback-controlled routing improves measurable resilience or changes information leakage compared with matched static and independently randomized routing methods. No cryptographic security advantage has yet been demonstrated.

Scientific status: Defined as a conceptual system and test plan. Dynamic routing does not create entropy, prove unpredictability, or neutralize side-channel attacks by itself.

03 / Evidence and falsification

Test the hypothesis—not the slogan.

UAQDR is intended to be evaluated against one-source, fixed-order multi-source, and independently randomized multi-source baselines. The comparison must hold hardware, sampling budgets, conditioning, and environments constant.

The primary outcomes are conservative entropy bounds, failure recovery, measured side-channel leakage, latency, throughput, and power consumption. Negative or inconclusive findings will be important.
